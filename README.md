# Nova (Android)

Chat AI app with API models (OpenAI-compatible, Anthropic, Gemini, free Pollinations). Debug build, not yet tested on many devices.

## Install
1. Download `Nova-debug.apk` from the [latest release](../../releases/latest).
2. Open it on your phone and allow "install from unknown sources" when asked.
3. Play Protect may warn: it is a developer build, not from the Play Store.

Not available on Android yet: on-device models, Python/JS, voice, calendar/alarms, photos/camera/file attachments, HTML preview.
